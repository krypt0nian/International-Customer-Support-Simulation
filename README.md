# International Customer Support Simulation

An Excel-based customer support tracker with 20 realistic international scenarios.
Use it to practice logging tickets, setting priorities, escalating issues, and
scheduling follow-ups. Built for **Microsoft Excel 2007 and later** (.xlsx, no macros).

## Features

- **Support Tracker:** logs Customer ID, issue category, priority, ticket status,
  resolution, escalation, and follow-up date for up to 200 tickets.
- **Automatic calculations:** days open, SLA target, SLA status, and follow-up alerts
  (Upcoming / Due Today / OVERDUE).
- **Customer Scenarios:** 20 cases from 20 countries with the customer message,
  challenge, skills tested, model answer, and escalation guidance.
- **Dashboard:** live counts and charts by status, priority, and category, plus
  escalation rate and SLA breaches.
- **Dropdown lists and colour coding** for consistent data entry.

## How to Use

1. Open `Customer_Support_Tracker.xlsx` in Excel.
2. Read a scenario on the **Customer Scenarios** sheet.
3. Update the matching ticket on **Support Tracker** (same Customer ID): set the status,
   write the resolution, mark escalation, and enter a follow-up date.
4. Compare your handling with the model answer, then check the **Dashboard**.

Yellow cells are inputs. Grey cells are formulas and should not be overwritten.

## Scenario Topics

Billing and payments, shipping and customs, GDPR/data privacy, account fraud,
product defects, refunds and returns, technical issues, language barriers,
cultural communication, time zones, and public social media complaints.

## Notes

- "GlobeCart" is a fictional company.
- SLA targets (Critical 1, High 2, Medium 3, Low 5 days) and the 30-day return policy
  are assumptions and can be edited on the **Lists** sheet.
- Rows 5-10 of the tracker are sample worked tickets; the rest are new tickets to work on.
